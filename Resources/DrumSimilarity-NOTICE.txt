Drum sound similarity uses LAION CLAP, laion/clap-htsat-unfused.

Audio-only CPU TorchScript conversion, with embedded Slaney log-mel preprocessing,
from Hugging Face Transformers ClapAudioModelWithProjection / ClapFeatureExtractor.
The Transformers library is Copyright Hugging Face, Inc. and contributors, Apache 2.0.
Original CLAP research: Yusong Wu et al., Large-scale Contrastive Language-Audio
Pretraining with Feature Fusion and Keyword-to-Caption Augmentation (2023).
No user audio is uploaded. No filenames, BPMs or tags are inputs to the model.
The first ten seconds are compared; shorter sounds use the checkpoint's repeat padding.
The cache is local drum-similarity.db; it contains derived sound and dynamics vectors.
